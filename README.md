# 🖼️ TheGreatesWallpaper.com — Legacy Web Project

A simple static nature wallpaper gallery website built using native **HTML5**, **CSS3**, and **Vanilla JavaScript** without any frameworks. This was my very first web project, marking the beginning of my journey in *web development*.

---

## ✨ Key Features

- **Aesthetic Image Gallery:** Displays a grid of high-resolution nature wallpapers with interactive hover zoom and transition effects.
- **Responsive Mobile Navigation:** An interactive hamburger menu for mobile devices powered by pure vanilla JavaScript.
- **Minimalist Design:** A clean, dark-themed layout optimized for viewing high-quality photography.
- **Multi-Page Architecture:** Composed of 4 traditional static pages:
  - `index.html` (Home)
  - `tentang.html` (About Us)
  - `kegiatan.html` (Activities / Photo Showcase)
  - `kontak.html` (Contact Us)

---

## 🛠️ Tech Stack

- **HTML5:** Structures the semantic content of the web pages.
- **CSS3:** Handles the page layout (utilizing *Flexbox* & *CSS Grid*), decorative styling, media queries for responsiveness, and hover animations.
- **Vanilla JavaScript:** Powers the interactive toggle logic for the mobile dropdown navigation menu.

---

## 🚀 Running the Project Locally

This project is lightweight and does not require any local web server (such as Node.js or Apache/PHP) to run.

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/pratama1246/pratama1246.github.io.git
   ```
2. **Navigate to the Project Folder:**
   ```bash
   cd pratama1246.github.io
   ```
3. **Run the Application:**
   Simply double-click (or right-click -> *Open with Browser*) the **`index.html`** file to view the website instantly in any modern web browser.
